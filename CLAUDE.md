# Instructions for AI agents

You are helping the Asele marketing team. Before writing anything:

1. Read `brand/voice.md` and follow it.
2. Read `context/product-facts.md`. Never invent features, numbers or medical claims.
3. Read `context/what-asele-is-not.md`. Asele does not diagnose.
4. Use the messaging pillars in `brand/messaging-house.md`.
5. Check `audiences/women.md` or `audiences/employers.md` so the copy speaks to the right person.

## Writing tasks

- LinkedIn posts: use `prompts/linkedin-post.md`.
- Newsletter: use `prompts/newsletter.md`.
- Podcast show notes: use `prompts/podcast-show-notes.md`.

## Processes

- Weekly content: follow `workflows/weekly-content.md`.
- New podcast episodes: follow `workflows/episode-launch.md`.

## Rules

- UK English, sentence case headings, no em dashes.
- Link every statistic to a reputable source, or leave it out.
- Never name or cite other women's health apps.
